# Исходные данные HackAlem AI

- `hackathon dataset anonymized .csv` — исходный анонимизированный каталог,
  66 профилей подрядчиков. Используйте его для подготовки runtime-данных.
- `hackathon dataset preview.html` — визуальное превью каталога.

CSV: UTF-8, разделитель колонок — запятая. Внутри полей `categories`,
`event_formats`, `languages`, `busy_dates` значения разделены `|`.
Пустой `max_hours` означает отсутствие указанного часового лимита.
Сохраняйте все `busy_dates` и флаги `synthetic`, `city_imputed`, `price_imputed`.

Сохранённая из браузера страница задания Google Docs не включена в Git:
она содержит данные аккаунта и служебные токены. Для передачи текста задания
нужен чистый экспорт документа, без метаданных браузерной сессии.

Чтобы получить файлы в своей рабочей ветке:

```bash
git fetch origin
git merge origin/main
```
