# Умный подбор подрядчиков

Сервис получает параметры event-заказа и возвращает до 3 подходящих подрядчиков
с конкретным объяснением выбора.

## Возможности

- Фильтрация по городу, дате, формату мероприятия, категории и бюджету.
- Необязательные условия: язык и длительность мероприятия.
- Исключение подрядчиков, занятых на выбранную дату по `busy_dates`.
- До 3 рекомендаций с детерминированным ранжированием.
- Explainability: объяснения на основе доступности, города, категории, формата,
  начальной цены и указанных условий по языку и длительности.
- Три статуса ответа: `matched`, `no_category_in_city`, `no_eligible_candidates`.
- Fallback-режим при сбое Core или некорректном ответе.
- Сохранение метаданных `synthetic`, `city_imputed`, `price_imputed`;
  UI показывает синтетические профили и сведения о восстановленных полях.

## Архитектура

```text
app.py
  ↓
helpers/utils.py
  ↓
core/generator.py
  ↓
catalog / fallback
```

Это схема пути запроса: helpers загружает каталог до вызова Core, передаёт его
в алгоритм и проверяет ответ. При сбое helpers возвращает fallback.

- `app.py` — Streamlit UI: форма заказа, карточки и диагностика отсутствия результатов.
- `core/generator.py` — обязательные фильтры (hard filters), scoring, ranking
  и фактические объяснения. Сортировка: score по убыванию, затем цена и ID по возрастанию.
- `helpers/utils.py` — загрузка каталога, нормализация, validation и fallback.
  Каталог хранится в `helpers/contractors.json`, аварийное демо — в `helpers/mock_data.json`.

## Data Contract

Пример request:

```json
{
  "city": "Алматы",
  "date": "2026-11-14",
  "event_format": "свадьба",
  "category": "Фотограф",
  "budget_kzt": 400000,
  "duration_hours": 8,
  "language": "русский"
}
```

Первые пять полей обязательны. Бюджет — положительное целое число в тенге.
`duration_hours` и `language` можно не передавать: helpers нормализует их в `None`.
Дата передаётся в Core в формате `YYYY-MM-DD`.

Основные поля ответа через `safe_pipeline_call`:

| Поле | Значение |
| --- | --- |
| `status` | `matched` — есть рекомендации; `no_category_in_city` — нет категории в городе; `no_eligible_candidates` — категория есть, но никто не прошёл условия |
| `query` | Параметры запроса, которому соответствует ответ |
| `results` | До 3 карточек; пустой список для двух статусов без рекомендаций |
| `meta` | Число кандидатов до и после фильтрации, число результатов и диагностика |
| `fallback` | `False` для штатного ответа Core, `True` для аварийного демо |

## Каталог

В `helpers/contractors.json` — **66 профилей**, из них **13 synthetic**.
Исходный анонимизированный CSV и HTML-превью находятся в `given_data/`.

- `busy_dates` — сохранённые занятые даты в формате `YYYY-MM-DD`.
- `synthetic` — признак синтетического профиля.
- `city_imputed` / `price_imputed` — город / цена восстановлены при подготовке данных.
- `max_hours: null` — часовой лимит не указан; такой профиль не исключается по длительности.

## Запуск

Выполните команды из корня репозитория. Единственная прямая внешняя зависимость —
Streamlit; она указана в `requirements.txt`.

```bash
python -m venv .venv
```

Windows (cmd):

```bat
.venv\Scripts\activate
```

Linux/macOS:

```bash
source .venv/bin/activate
```

После активации окружения:

```bash
pip install -r requirements.txt
python -m unittest discover -v
python -m streamlit run app.py
```

Откройте локальный адрес, который Streamlit выведет в терминале.

## Demo

Выберите Алматы, **2026-11-14**, свадьба, Фотограф, бюджет **400000 ₸**.
В дополнительных параметрах оставьте **8 часов** и **русский** язык.
Нажмите «Подобрать подрядчиков».

Ожидаются три результата: `HK-68220`, `HK-76268`, `HK-91112`.
Затем измените только дату на **2026-11-15** и повторите подбор.
Останутся `HK-68220` и `HK-91112`: у `HK-76268` дата 15 ноября есть в `busy_dates`,
а 14 ноября отсутствует. Выдача меняется из-за занятости; оба запроса возвращают
`matched` и `fallback: false`.

## Ограничения

- Сервис рекомендует подрядчиков; бронирование не выполняется.
- Ranking детерминированный. Объяснения формируются кодом; LLM в текущем Core
  не подключена и для работы не требуется.
- Доступность определяется сохранённым календарём. UI ограничивает даты
  диапазоном 2026-09-23 — 2026-12-31.
- Фильтр бюджета сравнивает начальную цену `price_from_kzt`, а не итоговую смету.
- При сбоях Core, невалидном ответе или превышении ожидания в 15 секунд helpers
  возвращает fallback. Это заранее подготовленный демо-сценарий: его `query`
  может отличаться от текущего запроса. Если mock недоступен, ответ будет пустым
  с `fallback: true`.
