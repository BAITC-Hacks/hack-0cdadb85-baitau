# Data & Storage Features

## Базовый каталог

- `helpers/contractors.json` содержит 66 исходных подрядчиков.
- Runtime-операции загрузки и сохранения пользовательских профилей не изменяют исходный каталог.
- Флаги `synthetic`, `city_imputed` и `price_imputed` сохраняются при загрузке.
- Занятые даты `busy_dates` сохраняются и валидируются в формате `YYYY-MM-DD`.

## Feature-каталог

`helpers/contractors_feature.json` — отдельное хранилище пользовательских подрядчиков,
изначально содержащее `[]`. Новые записи сохраняются только в этот файл.
Базовый каталог не изменяется: общий список состоит из base-профилей, за которыми
следуют feature-профили в порядке сохранения.

## API helpers

Функции находятся в `helpers/utils.py`:

| Функция | Назначение |
| --- | --- |
| `load_feature_contractors()` | Загружает и проверяет feature-профили. Отсутствующий, пустой файл или `[]` дают пустой список. Невалидное содержимое вызывает `ValueError`, файл не перезаписывается. |
| `save_feature_contractor(contractor)` | Проверяет полный contractor contract, отклоняет повторный ID, добавляет профиль в feature JSON и возвращает сохранённый dict. Входной dict не изменяется. |
| `generate_feature_id()` | Возвращает следующий ID по максимальному номеру среди сохранённых `USR-*`. |
| `load_all_contractors()` | Возвращает `load_contractors() + load_feature_contractors()`. Базовый загрузчик по-прежнему возвращает только 66 исходных профилей. |

Пользовательские профили сохраняются с `synthetic=True`, `city_imputed=False`
и `price_imputed=False`.

## ID

```text
USR-00001
USR-00002
...
```

Нумерация начинается с 1, использует минимум пять цифр и вычисляется из файла,
поэтому не сбрасывается после перезапуска. Берётся максимальный номер плюс один,
а не количество записей. Генерация не резервирует ID: параллельные формы могут
получить одинаковое значение, но сохранение дубликата отклоняется.

## Validation

Перед сохранением проверяется существующий contractor contract и дополнительные
ограничения пользовательских профилей:

- `anon_name` — обязательное непустое имя.
- `categories` — непустой список непустых строк.
- `city` — обязательная непустая строка.
- `price_from_kzt` — целое число строго больше 0; `bool` не принимается.
- `event_formats` и `languages` — непустые списки непустых строк.
- `description` — обязательное непустое описание.
- `max_hours` — `int > 0` или `None`; `bool` не принимается.
- `busy_dates` — `list[str]` с валидными датами `YYYY-MM-DD`; допустим `[]`.

## Reliability

- Duplicate ID отклоняется с `ValueError` до записи.
- Malformed feature JSON не портит базовый каталог: `load_contractors()` продолжает
  загружать 66 профилей. Feature-загрузчик и общий загрузчик сообщают об ошибке;
  повреждённый файл автоматически не очищается.
- Запись атомарная: временный файл в том же каталоге заменяет целевой через `os.replace`.
- JSON сохраняется в UTF-8 с `ensure_ascii=False` и `indent=2`.
- Блокировка защищает параллельную запись потоков одного процесса.
  Одновременная запись из нескольких процессов не поддерживается.
- Тесты хранения используют временный файл и подмену пути, не загрязняя реальный
  `helpers/contractors_feature.json`. Проверяются повторная загрузка, дубликаты,
  повреждённые данные, ошибки записи и сохранность базового каталога.
