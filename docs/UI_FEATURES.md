# Marketplace UI Features

Пользовательский интерфейс построен на Streamlit (`app.py`) и реализует двухсторонний marketplace flow с разделением ролей между клиентами и специалистами event-индустрии без необходимости авторизации.

## Role selection

- **Роли:** «Заказчик (подбор специалистов)» и «Подрядчик (регистрация профиля)».
- **Переключение:** горизонтальный переключатель роли на главном экране.
- **Управление состоянием:** активная роль синхронизируется через `st.session_state` (`current_role` и ключ виджета `role_radio_select`).
- **Навигация:** переключение доступно в любой момент; после успешной регистрации подрядчика доступна прямая кнопка перехода к поиску в роли заказчика.

## Customer flow

Интерфейс подбора специалистов под параметры мероприятия:

- **Основные параметры:**
  - Город: Алматы, Астана, Зарубежье.
  - Дата мероприятия: выбор даты в диапазоне датасета (с 23.09.2026 по 31.12.2026, по умолчанию 14.11.2026).
  - Формат мероприятия: свадьба, той, корпоратив, конференция, юбилей, день рождения.
  - Категория: динамический список категорий на основе актуального каталога.
  - Бюджет: числовой ввод в тенге с шагом и форматированием.
- **Дополнительные параметры (сворачиваемый блок):**
  - Длительность: опциональный слайдер (1–16 ч) с возможностью отключения привязки к часам.
  - Язык: выбор рабочего языка (Любой, русский, казахский, английский).
- **Результаты:**
  - До 3 ранжированных карточек исполнителей (Top-3).
  - Адаптивные карточки с бейджами (цена, теги языков, лимит часов, пометка синтетического профиля).
  - Фактические обоснования (`explanations`): блок «Почему этот подрядчик подходит», сформированный ядром рекомендаций.
  - Диагностика отказов (`diagnostics`): при статусе `no_eligible_candidates` выводятся понятные счётчики причин (занятость, превышение бюджета, формат, язык, длительность).
  - Индикатор демо-режима: при переходе на fallback выводится метка «Демо-режим».

## Contractor flow

Форма регистрации нового исполнителя для участия в выдаче:

- **Имя / Название:** обязательное текстовое поле (по умолчанию предзаполнено `Nova Photo` для быстрого демонстрационного сценария).
- **Город базирования:** выбор из поддерживаемых городов (Алматы, Астана, Зарубежье).
- **Цена от (₸):** числовое поле стоимости услуг от (минимальное значение > 0).
- **Категории услуг:** множественный выбор категорий из актуального каталога.
- **Форматы мероприятий:** множественный выбор форматов (свадьба, той, корпоратив и др.).
- **Языки:** множественный выбор рабочих языков (русский, казахский, английский).
- **Максимум часов:**
  - Чекбокс «Работа не привязана к присутствию на площадке» (`max_hours = None`).
  - Числовой ввод лимита часов (от 1 до 24 ч), если привязка есть.
- **Описание услуг:** текстовое описание специализации и опыта.
- **Календарь занятости:** на первом этапе создаётся с `busy_dates: []` (подрядчик свободен на все даты).

## Save flow

- **Генерация ID:** вызывается `helpers.utils.generate_feature_id()`, выдающий идентификатор формата `USR-XXXXX`.
- **Сохранение:** передача объекта подрядчика строго через публичный API `helpers.utils.save_feature_contractor(contractor)`.
- **Обработка ошибок:** клиентская валидация формы и ошибки валидации хранилища перехватываются и отображаются в интерфейсе через `st.error()`.
- **Изоляция:** прямой записи в JSON-файлы из `app.py` нет; сохранение атомарно выполняется модулем хранения данных.

## Live refresh

- Каталог для подбора загружается через `helpers.utils.load_all_contractors()` при каждом рендере страницы.
- Загрузка объединяет 66 базовых профилей и сохранённые feature-профили.
- Вновь зарегистрированный специалист становится доступен для поиска заказчиками мгновенно, без перезапуска приложения или процесса Streamlit.

## Demo

Короткий сквозной сценарий (E2E):

1. Открыть приложение и выбрать роль **«Подрядчик»**.
2. Подтвердить данные профиля **Nova Photo** (Алматы, Фотограф, 180 000 ₸, свадьба, русский, 8 ч, описание) и нажать **«Зарегистрировать подрядчика»**.
3. Убедиться в получении идентификатора `USR-XXXXX` и нажать **«Перейти к подбору как заказчик»**.
4. В роли **«Заказчик»** указать: Алматы / 2026-11-14 / свадьба / Фотограф / бюджет 200 000 ₸ / 8 ч / русский.
5. Нажать **«Подобрать подрядчиков»** — **Nova Photo** моментально появляется в выдаче Top-3 с объяснением соответствия и `fallback=False`.

## Current limitations

Честно зафиксированные ограничения текущей версии:

- **Авторизация:** отсутствует система аккаунтов, паролей, ролевой сессии (auth/login).
- **Редактирование:** нет функционала обновления данных уже сохранённых профилей.
- **Удаление:** нет возможности удалить профиль через интерфейс.
- **Календарный UI:** отсутствует визуальный календарь для интерактивной разметки занятых дат (`busy_dates`).
- **Бронирование:** нет оформления заказа, корзины, платежей или резервирования дат на стороне заказчика.
